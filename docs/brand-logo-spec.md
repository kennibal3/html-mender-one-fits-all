# HTML课件互动编辑系统 V1.0 品牌标志设计说明

## 设计目标

新版标志用于“HTML课件互动编辑系统 V1.0”的应用图标、安装包、用户手册和软件著作权材料。标志应在不依赖文字的情况下表达“课件画布、HTML代码与互动连接”，并在 16×16 至 1024×1024 像素范围内保持辨识度。

## 核心构图

- 圆角方形外轮廓代表完整的软件工作空间。
- 中央浅色圆角画布代表 HTML 教学课件。
- 一对蓝色尖括号代表 HTML 与代码结构。
- 青绿色连接路径和三个节点代表触发、响应与结果。
- 中心节点的双环结构代表可视化点击与互动配置。

## 色彩规范

- 科技蓝：`#176BFF`
- 深蓝：`#0B4FC4`
- 互动青绿：`#13B8A6`
- 浅色画布：`#F7FBFF`
- 标题深色：`#102A43`
- 白色：`#FFFFFF`

主图标允许使用科技蓝到深蓝的轻微渐变。小尺寸图标使用纯色背景，减少渐变、阴影和非必要细节。

## 使用规则

- 应用图标只使用图形标志，不在图标内部加入中文或英文文字。
- 中文组合版由图形标志、软件全称和版本号组成。
- 不拉伸、不旋转、不改变节点数量，不使用未经定义的颜色。
- 深色背景优先使用主图标；单色印刷或极小尺寸使用纯色小尺寸版。
- 图形四周应保留不少于图标宽度 8% 的安全空间。

## 交付资产

- `logo-symbol.svg`：主图标矢量源文件。
- `logo-symbol-flat.svg`：纯色小尺寸版本。
- `logo-lockup-zh.svg`：中文横向组合版。
- 后续确认后生成 PNG、ICNS 和 ICO，并替换应用现有图标。

## 决策记录

1. 完全重新设计，不继承旧 Logo 的文档折角或“HM”字母造型。
2. 采用现代教育科技风，而非机构徽章或儿童化课堂风格。
3. 采用科技蓝与互动青绿作为主色。
4. 图标与中文名称分离，保证小尺寸可读性。
5. 采用确定性的 SVG 几何图形，便于说明设计来源、维护和多尺寸导出。
